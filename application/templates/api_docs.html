🔷 Базовый URL

http://ваш-домен/api/v1/

🔐 Аутентификация

Для защищённых эндпоинтов используйте Bearer токен в заголовке:

Authorization: Bearer ваш_токен

Токен получается при входе через /api/v1/login

🔷 Аутентификация

POST /api/v1/login Публичный

Вход в систему и получение токена доступа.

Тело запроса (JSON):

{
    "email": "user@example.com",
    "password": "password123"
}

Ответ:

{
    "success": true,
    "message": "Вход выполнен успешно",
    "data": {
        "user": {
            "id": 1,
            "name": "Андрей",
            "email": "user@example.com",
            "role": "admin"
        },
        "token": "a1b2c3d4e5f6...",
        "expires_in": 1734567890.123
    }
}

POST /api/v1/logout Требует токен

Выход из системы (удаление токена).

Ответ:

{
    "success": true,
    "message": "Выход выполнен успешно"
}

GET /api/v1/me Требует токен

Получение информации о текущем пользователе.

Ответ:

{
    "success": true,
    "data": {
        "id": 1,
        "name": "Андрей",
        "email": "user@example.com",
        "role": "admin",
        "last_login": "2026-08-13 16:00:22"
    }
}

📝 Посты

GET /api/v1/posts Публичный

Получение списка постов с пагинацией и фильтрацией.

Параметры запроса:

ПараметрТипОписание
pageintegerНомер страницы (по умолчанию 1)
per_pageintegerКоличество постов на странице (по умолчанию 5)

Пример: /api/v1/posts?page=2&per_page=10

Ответ:

{
    "success": true,
    "data": [
        {
            "id": 1,
            "title": "Мой первый пост",
            "content": "Полный текст поста...",
            "author_id": 1,
            "created_at": "2026-08-13 16:00:22",
            "author": "Андрей",
            "category": "Технологии"
        }
    ],
    "pagination": {
        "page": 1,
        "per_page": 5,
        "total": 12,
        "total_pages": 3
    }
}

GET /api/v1/posts/{id} Публичный

Получение конкретного поста по ID.

Ответ:

{
    "success": true,
    "data": {
        "id": 1,
        "title": "Мой первый пост",
        "content": "Полный текст поста...",
        "author_id": 1,
        "author_name": "Андрей",
        "category_name": "Технологии",
        "created_at": "2026-08-13 16:00:22"
    }
}

POST /api/v1/posts Требует токен

Создание нового поста.

Тело запроса (JSON):

{
    "title": "Заголовок поста",
    "content": "Содержание поста...",
    "category_id": 1
}

Ответ:

{
    "success": true,
    "data": {
        "id": 10,
        "title": "Заголовок поста",
        "content": "Содержание поста...",
        "category_id": 1,
        "author_id": 1
    },
    "message": "Пост успешно создан"
}

PUT /api/v1/posts/{id} Требует токен

Обновление поста (автор или администратор).

Тело запроса (JSON):

{
    "title": "Новый заголовок",
    "content": "Новое содержание...",
    "category_id": 2
}

Ответ:

{
    "success": true,
    "data": {
        "id": 10,
        "title": "Новый заголовок",
        "content": "Новое содержание...",
        "category_id": 2
    },
    "message": "Пост успешно обновлён"
}

DELETE /api/v1/posts/{id} Только админ

Удаление поста (только для администраторов).

Ответ:

{
    "success": true,
    "message": "Пост успешно удалён"
}

📋 Коды ответов

Код Описание
200✅ Успешный запрос
201✅ Успешно создан
400❌ Ошибка в запросе
401🔒 Требуется аутентификация
403🚫 Недостаточно прав
404🔍 Ресурс не найден
500💥 Внутренняя ошибка сервера

💻 Пример использования с JavaScript (Fetch API)

// Получение постов
fetch('/api/v1/posts')
    .then(response => response.json())
    .then(data => console.log(data));

// Вход в систему
fetch('/api/v1/login', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({
        email: 'user@example.com',
        password: 'password123'
    })
})
.then(response => response.json())
.then(data => {
    const token = data.data.token;
    console.log('Токен:', token);
});

// Создание поста
fetch('/api/v1/posts', {
    method: 'POST',
    headers: {
        'Content-Type': 'application/json',
        'Authorization': 'Bearer ваш_токен'
    },
    body: JSON.stringify({
        title: 'Новый пост',
        content: 'Содержание...',
        category_id: 1
    })
})
.then(response => response.json())
.then(data => console.log(data));
